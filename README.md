
# 👨‍💼 Employee Data Analysis — Pandas

A small practical project using **Python Pandas** to analyze employee data stored in a CSV file.

### 📌 Topics Covered
- Reading CSV files
- Selecting rows and columns
- Filtering data
- Finding youngest & oldest employees
- Average and median salary
- Sorting employee records
- Basic data analysis

### 🛠️ Technologies
- Python 🐍
- Pandas 🐼
- CSV
